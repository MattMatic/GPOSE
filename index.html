Prefix

`+` must exist; `*` adjust glyph (implies `+`) - no space before glyph name!

Delta

Use form `GLYPH<ID:VAL,ID:VAL>`
- where ID=dx,dy,ax,ay - to find delta values.
- where VAL is a value or `*` = anything, `+` = any positive, `-` = any negative.
e.g. `ALIFf1<dx:-60 ax:100>`
e.g. `sda<dx:* dy:->`

Use `/.../` for regular expressions.
e.g. `/.+/` to find any glyph.
